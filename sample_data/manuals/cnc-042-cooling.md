# FX-400 Coolant Loop Service Manual (fictional)

Asset: CNC-042
Model: ForgeMach FX-400
Document type: cooling system

## Purpose

This fictional manual describes the closed-loop coolant system on CNC-042.
It is not a manufacturer publication.

## Overheating symptoms

A blocked or starved coolant loop raises spindle temperature. Operators may
see repeating TEMP_HIGH alarms, declining coolant flow, and a hot spindle
housing. Do not keep the machine in production while coolant flow is falling.

## Inspection interval

Inspect the coolant strainer, pump discharge, and return line every 90 days.
An overdue cooling system inspection is a known precursor to overheating on
the FX-400.

## Corrective work

1. Stop the spindle if TEMP_HIGH is active.
2. Restore coolant flow before resetting alarms.
3. Open a work order to inspect the coolant loop and replace a clogged filter
   if flow does not recover.
